# Mask Editor

Локальный веб-редактор чёрно-белых сегментационных масок для iPad + Apple Pencil. Работает в Safari на iPad, а сами PNG хранятся на компьютере под Windows **или** macOS. Интернет во время редактирования не требуется.

## Быстрый старт на Windows

1. Распакуйте ZIP целиком в удобную папку на Windows.
2. Установите **Python 3** с [python.org](https://www.python.org/downloads/), если он ещё не установлен. При установке желательно выбрать «Add python.exe to PATH»; скрипт также использует стандартный запуск `py -3`.
3. Дважды щёлкните **`start_windows.bat`**. Первый запуск создаст виртуальное окружение и установит Pillow (для этого один раз требуется интернет). Для пробного запуска откроются две пары из папки `sample_data` — копии предоставленных примеров.
4. В окне появится адрес вида `http://192.168.1.100:8765/?token=...`. Откройте **полный адрес вместе с `?token=...`** в Safari на iPad. iPad и компьютер должны находиться в одной локальной сети. Если Windows запросит разрешение для Python в брандмауэре, разрешите доступ **только для частных сетей**.
5. Выберите пару, отредактируйте маску Apple Pencil, нажмите «Сохранить». Существующий файл `__MASK__...png` будет **заменён на месте**.

**Чтобы открыть свою папку:** перетащите папку с PNG мышью на файл `start_windows.bat`. Её полный путь будет передан программе. Альтернатива — открыть командную строку в папке редактора и выполнить:

```bat
start_windows.bat "D:\Dataset"
```

## Быстрый старт на Mac

1. Распакуйте ZIP; убедитесь, что установлен Python 3 (версия 3.10 или новее).
2. Откройте приложение «Терминал» и перейдите в распакованную папку, например: `cd ~/Downloads/wheat-mask-editor`.
3. Запустите:

```bash
./start_mac.command "/Users/USERNAME/Dataset"
```

Если не передавать путь к папке, будут открыты две демонстрационные пары из `sample_data`. При первом запуске Pillow устанавливается автоматически.

4. Откройте адрес с токеном из Терминала в Safari на iPad. При необходимости разрешите входящие подключения Python в настройках macOS.

## Как устроено определение пар

Программа группирует PNG по **полной строке до маркера `__IMAGE__` или `__MASK__`**. Например:

```
Frost_wheat_3T1__IMAGE__mask_preview.png
Frost_wheat_3T1__MASK__object_01.png
```

Идентификатор пары: `Frost_wheat_3T1`.

Одна `IMAGE` может соответствовать нескольким `MASK` — тогда каждая маска становится отдельной позицией списка. Пары ищутся рекурсивно во вложенных папках, но **только в пределах одной директории**: одинаковые идентификаторы из разных каталогов не перепутаются. Если несколько `IMAGE` имеют одинаковый префикс в одной папке, такая группа пропускается с предупреждением. Файлы с несовпадающими разрешениями также пропускаются.

## Редактирование и навигация

- **Кисть** добавляет белые пиксели (255), **ластик** — чёрные (0). Размер в пикселях исходной маски, 1–400 px. Сглаживание границ кисти не применяется, первоначальные полутоновые пиксели сохраняются, пока вы их не закрасите.
- **Apple Pencil** рисует; **один палец** перемещает изображение, **два пальца** масштабируют его. Мышью: левая кнопка рисует, правая/средняя перемещает, колесо масштабирует.
- Режимы **Наложение** (розовая маска на RGB с регулируемой непрозрачностью), **RGB** и **Маска**. При сильном увеличении можно включить пиксельную сетку.
- **Назад** / **Вперёд** перебирают пары. В случае несохранённых изменений редактор спрашивает, сохранить их, отбросить или отменить переход. Кнопка **Сохранить →** сразу сохраняет текущую маску и открывает следующую.
- Поиск по полному идентификатору, имени RGB/MASK и пути. Список сортируется «естественным» образом (2 перед 10). Последняя выбранная пара запоминается в браузере.
- **Undo/Redo:** до 50 мазков, пока текущая пара открыта. **Ctrl/Cmd+S** — сохранить, **Ctrl/Cmd+Z** — отменить, **Ctrl/Cmd+Shift+Z** — повторить, **B/E** — кисть/ластик, **0** — вписать, **←/→** — соседняя пара, **/** — поиск.

## Как происходит сохранение

Код передаёт на компьютер одноканальный 8-битный массив маски исходного размера. Сервер на Python с Pillow сравнивает его с исходным PNG. Для поддерживаемых масок в оттенках серого он **сохраняет значения каждого нетронутого пикселя и альфа-канал**, а изменённым пикселям записывает 0 или 255. В примерах `RGBA` результат также остаётся `RGBA` того же размера. Если исходная маска содержит цветные пиксели, редактор не пытается её молча преобразовать — сообщит об ошибке.

Результат сначала полностью записывается во **временный файл в той же директории**, затем системной операцией заменяет **ровно исходный файл `MASK` с прежним именем**. Это не отдельная папка готовых масок. Перед заменой проверяется версия PNG: если он был изменён в другой программе после загрузки на iPad, сохранение отменяется, чтобы избежать потери данных.

**Внимание:** кнопка «Сохранить» действительно перезаписывает исходную маску. Убедитесь, что резервная копия существует, а для первого теста используйте `sample_data`. При перебоях синхронизации Google Drive могут возникнуть конфликты версий — проверяйте состояние синхронизации, особенно перед работой с большими сериями.

## Ограничения первой версии

- Требуется запущенный компьютер с сервером и доступная локальная сеть; из интернета сервер открывать **не нужно**.
- Маски должны быть PNG с 8-битными значениями оттенков серого, в режимах `L`, `LA`, `RGB` или `RGBA`; разрешение до 45 млн пикселей. Для `RGB/RGBA` каналы R, G и B должны быть идентичны.

## Безопасность

Сервер слушает локальную сеть (`0.0.0.0:8765`) и выдаёт **случайный токен при каждом запуске**. Не публикуйте ссылку с токеном, не открывайте порт 8765 на роутере и разрешайте Windows Firewall доступ только из **частной** сети. Любой, кто получит ссылку и сетевой доступ к серверу, сможет менять маски в выбранной папке. Для тестирования вне своей домашней сети сначала понадобится другой, защищённый способ подключения.

Остановить сервер можно клавишами **Ctrl+C** в его окне.
